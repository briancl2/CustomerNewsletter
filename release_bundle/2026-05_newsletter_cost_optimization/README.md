## Boundary

This bundle does not claim billing savings, durable percentage savings, model superiority, or fleet-wide transfer. Treat telemetry, usage reports, and workflow observations as engineering signals unless you are working from invoice-grade billing data. Where a feature is marked `GA` or `PREVIEW`, the label is tied to the linked first-party source.
